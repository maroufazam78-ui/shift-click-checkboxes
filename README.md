# Shift Click Checkboxes

An interactive JavaScript project that allows users to select multiple checkboxes by holding the **Shift** key while clicking.

## 🚀 Features

- Shift + Click multiple selection
- Clean and responsive layout
- Built without any libraries or frameworks
- Beginner-friendly JavaScript project

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## 📚 What I Practiced

- DOM Selection
- Event Listeners
- Keyboard Events
- Checkbox State Management
- JavaScript Loops
- Conditional Logic
